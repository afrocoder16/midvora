# First Light — Midvora homepage artwork

The homepage uses a custom cobalt glass and amber sun study inspired by the user's meaning for Midvora: Midwest + light. The built-in imagegen tool generated the first asset and edited it into a second lighting study. Responsive AVIF/WebP versions are generated by Astro at build time. The lighting buttons switch between these two images, with reduced-motion support.

## Motion and offer update

The floating island header uses the original `public/img/new logo.png`. Two angled, counter-scrolling tapes lead into the offer numbers. The process illustrations are native CSS/SVG: layered note paper, a dimensional browser, and an origami launch. The cobalt pricing section explicitly includes hosting, security, and weekly maintenance in the $525 starting offer, following the user's current instructions.

`src/styles/home-motion.css` animates the glass study, traveling ring highlights, tapes, and process artwork. `src/scripts/home-motion.ts` starts loops only while their sections are near the viewport, handles the shared pause button and reduced-motion preference, and adds brief scroll reveals and number counts. Text keeps its full opacity during reveals. There is no custom cursor, animation library, or continuous JavaScript render loop. `?staticPreview` disables motion for review; all content remains visible without JavaScript.
